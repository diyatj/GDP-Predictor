# GDPredict

A web application that predicts the GDP of various countries using a linear regression machine learning model.

## Setup
1. Clone repository
```bash
git clone https://github.com/diyatj/GDP-Predictor.git
```

2. Install dependencies
```bash
pip install streamlit
```

3. Run code
```bash
streamlit run Home.py
```

4. Open web link

	Ctrl + click on Local URL to open in default browser

## Features

- Home landing page with prediction model
- Project overview with details
- Description of GDP and factors
- About page for team members
